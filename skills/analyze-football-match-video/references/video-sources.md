# Video source handling

## General sequence

1. Confirm the link or file is the intended match.
2. Record the displayed duration and the timestamp format.
3. Check whether the player can be identified at the first requested interval.
4. Test seeking at an early, middle, and late timestamp before planning the review.
5. Record whether playback is continuous, segmented, delayed, or restricted.
6. For a full-player review, create a coverage map of every identified playing interval and mark each range complete only after it has been watched for receptions.

## Veo and similar panoramic players

- Prefer the wide tactical view for off-ball positioning and team shape.
- Use player-follow or zoom views only after identity is stable.
- Watch for automatic camera tracking that temporarily follows the wrong ball or group.
- Treat overlay clocks and exported-video clocks as separate timebases until confirmed.

## YouTube

- Note whether chapters, ad breaks, intros, halftime edits, or livestream gaps shift match time relative to video time.
- Use video timestamps in the evidence ledger and add match-clock equivalents only when the offset is reliable.
- Do not rely on autogenerated chapters as football phases.

## Google Drive and other signed-in sources

- Use the user's existing authenticated browser when required.
- Do not request passwords, copy session data, or expose private share parameters.
- If embedded preview seeking is unreliable, ask for an uploaded clip or permitted download rather than pretending coverage is complete.

## Uploaded or local video

- Confirm whether the file contains the full match, a half, or selected clips.
- Preserve the original file and analyze non-destructively.
- When clips restart at `00:00`, label them with a clip name plus local timestamp.

## Continuous individual review

- First scan broadly to locate the player's entries, exits, side changes, and periods when identity is lost.
- Review each confirmed playing interval from start to finish. Use faster playback only when ball contact and identity remain reliably visible; return to normal or slower speed around every involvement.
- After logging a reception, resume from a small overlap before the end of the event so the next quick combination is not skipped.
- Maintain a coverage checklist. Camera cuts, buffering jumps, unavailable segments, and unresolved identity gaps remain incomplete until rechecked.
- If the player is temporarily off-camera, do not infer a reception from team movement alone.

## Inaccessible sources

Offer the smallest viable alternative:

1. A working link or uploaded full match.
2. The target player's complete playing intervals.
3. Clips around each marked event when only event verification is needed.
4. Screenshots or short screen recordings.
5. Timestamped notes for a provisional, clearly limited review.

Do not convert note-only analysis into video-backed claims.
